# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

- **Do NOT open a public issue or discussion** for sensitive security reports.
- Please email the maintainer at `linus@kang.id.au` or open a private security advisory through GitHub:
  [GitHub Security Advisories](https://github.com/linuskang/review-dash/security/advisories/new).

Please include:
1. A description of the issue and potential impact.
2. Steps to reproduce or proof-of-concept.
3. Any suggested mitigation or patch, if available.

We will acknowledge receipt within 48 hours and work with you to address and publish a fix before public disclosure.
